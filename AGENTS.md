# Agents working in this repo

- Project rules: `CLAUDE.md`, and the skill it names for the area in
  `.claude/skills/<name>/SKILL.md`.
- Git, commits, merges and who does what: `.github/copilot-instructions.md`.
- Before any commit or merge: `npm run agent:check` (the pre-commit hook runs it too).

The rules live only in those files, so this one cannot go out of date.
